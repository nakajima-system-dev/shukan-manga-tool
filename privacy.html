習慣マンガ投稿ツール：プライバシー

プライバシーについて

取得・使用する情報

接続したYouTubeチャンネルのID：指定された自分のチャンネルであることの確認に使います。

投稿する動画、タイトル、説明文、子ども向け設定、制作方法に関する設定：YouTubeへの非公開投稿に使います。

投稿済み動画のID、公開範囲、処理状況：投稿結果の確認に使います。

Googleの継続接続情報：毎回ログインせずに、承認された操作を実行するために使います。

Gmailのメール本文、Google Driveのファイル、連絡先を読む権限は要求しません。

対象動画のコメント本文、コメントID、投稿者の識別情報、既存の返信：承認済みの返信条件との照合、二重返信の防止、対応が必要なコメントの確認に使います。公開動画の再生数・高評価数・コメント数は作品改善の参考にします。

保存する場所

継続接続情報は運営者本人のPC内の専用フォルダに保存します。現実装の保存ファイルは暗号化されておらず、Windowsの利用者アカウントとPC自体の保護に依存します。秘密情報をソースコード管理や一般公開ページに含めません。

動画の内容を特定するハッシュ値、承認に対応する識別値、投稿日時、動画ID、結果の記録もPCに保存します。ハッシュ値は、動画ファイルが同じ内容か照合するための値です。

自動返信の台帳にはコメントID、返信ID、処理結果、投稿者の識別情報を変換した値を保存します。自動返信の台帳には元コメント本文や投稿者名を保存しません。公開コメントの調査用資料は別にPC内へ保存することがあり、自動返信の台帳とは区別します。

外部との通信

認証・更新にはGoogleの認証サービス、投稿・状態確認・コメントの取得と返信にはYouTubeの公式APIを利用します。返信文はYouTubeへ送信され、対象コメントの返信として公開されます。自動返信の文面選択では外部の文章生成AIへコメントを送信しません。動画と投稿情報はGoogleへ送信され、投稿した動画はGoogle側にも保存されます。Google側の取り扱いはGoogleのプライバシーポリシーとYouTubeの規約に従います。

運営を補助するAIアシスタントが、投稿の成否などの作業記録を確認することがあります。接続キーや継続接続情報の値を、チャット本文や公開ログへ表示しない運用とします。取得したGoogleのユーザーデータを広告のターゲティングや販売に利用せず、AIモデルの学習用として提供しません。

Google APIから受け取った情報の利用は、Google API Services User Data Policyおよび該当するLimited Useの要件に従います。

接続停止とデータの取り扱い

Googleアカウントの「サードパーティとの接続」から、本ツールの許可を取り消せます。定時投稿と自動返信は、それぞれWindowsの専用タスクを無効にして停止できます。自動返信にはPC内の停止ファイルによる停止方法もあります。開始済みの通信は取り消せない場合があります。

接続解除だけでは、PC内の記録やYouTube上の動画は削除されません。PC内の接続情報・記録、YouTube上の投稿動画は別々に管理し、削除が必要な場合は運営者本人が確認して処理します。記録を消して既存作品を再度自動投稿する運用は行いません。
